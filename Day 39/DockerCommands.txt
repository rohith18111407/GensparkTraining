Alpine Container

-i interactive mode
-t stands for pseudo terminal
alpine is the image name
/bin/sh is the place where you want to run the image

docker run -it alpine /bin/sh 
 

Inside the pseudo terminal, you can run all the linux commands

pwd

whoami

ls

exit 

Provide Logs of a container

docker logs <container_id> 

Remove Docker Image

 docker rmi <image_id>

Note:

1. Always stop the container if it is running.

docker stop <container_id>

1. Then remove the container
 docker rm <container_id>  

1. After all these steps you could remove the docker image.
docker rmi <image_id>
